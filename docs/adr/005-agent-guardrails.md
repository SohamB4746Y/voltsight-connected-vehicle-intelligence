# ADR-005 Agent guardrail model (Charge Ops Copilot)
**Decision:** the guardrails live **outside the model**: a fixed allow-list of eight typed tools; strict argument validation (unknown fields rejected); permission and subscription checks per tool; the caller's tenant/role from the verified token only; per-message budgets (5 rounds, 6 tool calls); every call audited (`actor_type = agent`, hashed arguments, evidence refs); answers must cite evidence ids that exist in tool results or say "insufficient evidence"; retrieved text is flagged untrusted; writes are two-phase (the agent can only register a pending action — approval is a separate human endpoint needing `plans.write`, single use, tenant-bound).
**Providers:** a deterministic rule-based provider (default, CI, fallback) and a Claude tool-use provider selected by `ANTHROPIC_API_KEY` (**not exercised in this repository — no key was available**). **Vector search:** pgvector HNSW over a 384-d hashing embedder (lexical; recall@5 0.958 on the labelled paraphrase set — a limitation, a semantic model is a drop-in).
