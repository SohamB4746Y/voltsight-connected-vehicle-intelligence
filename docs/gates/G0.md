# Gate G0 — Toolchain, repo, CI skeleton, base infra, observability base

Written **before** implementation (loop protocol, plan §5.1). Status values: PASS / PARTIAL / FAIL / BLOCKED. Evidence lives in `evidence/G0/<UTC>-<git sha>/`.

## Acceptance criteria
| # | Criterion | How verified | Artefact |
|---|---|---|---|
| G0.1 | Required CLIs installed and report a version: docker, docker compose, go, kubectl, helm, kind, terraform, k6, buf, gh, trivy, syft, gitleaks, hadolint, tflint, python, node | `make gate-G0` (`tools/gates/g0.py`) | `env.json` |
| G0.2 | Docker engine has >= 11 GB memory and >= 12 CPUs available | `docker info` | `env.json` |
| G0.3 | Host disk free, CPU, RAM baseline recorded | script | `env.json` |
| G0.4 | `make up` from **clean volumes** brings every base service to healthy (`docker compose up --wait`) | script times it | `results.json` (`time_to_healthy_s`) |
| G0.5 | Each service answers a functional probe (not just "container running"): Kafka metadata, Postgres+pgvector extension, ClickHouse query, Redis auth+PING, S3 bucket create/put/get, Keycloak realm endpoint, Vault status, OTel health, Prometheus targets, Grafana datasource | script | `results.json` (`probes`) |
| G0.6 | Idle memory footprint of the stack measured (baseline for budget) | `docker stats` | `results.json` (`idle_mem_mb`) |
| G0.7 | Telemetry plumbing works: OTLP span/metric sent to collector appears in Prometheus (collector self-metrics scraped) | script | `results.json` |
| G0.8 | Static checks clean: `docker compose config`, yamllint, gitleaks (no secrets), no `.env` committed | CI + local | CI run, `results.json` |
| G0.9 | CI skeleton workflow passes on GitHub (compose validate, gitleaks, trivy fs, unit-test placeholder for tools) | GitHub Actions | CI URL |
| G0.10 | `.env` secrets are generated randomly per checkout (no fixed credentials in repo) | `tools/dev/gen_env.py` + gitleaks | CI |

## Failure conditions
Any service unhealthy after 5 min; probe failing; secrets in git; CI red; versions missing from env.json.
