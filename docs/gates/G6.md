# Gate G6: range-risk engine and critical alerts (M5)

Rows covered: AL1, AL10, N4, X5. Evidence: `evidence/G6/`.

## What is built
`internal/rangerisk`: per-(city, tenant) **multi-source reverse Dijkstra overlay** (distance from every graph node to the nearest *available* charger usable by that tenant), incremental update on charger status change, O(1) per-event lookup; **A\*** route evidence for an alert; range estimators (baseline rule, per-vehicle EWMA); decision rule with hysteresis and deterministic alert windows. It plugs into the stream worker (`rtp.Processor`) and publishes `alerts.v1`; `cmd/vsalerts` persists alerts idempotently to PostgreSQL and fans them out on Redis pub/sub.

## Acceptance criteria
| # | Criterion | Verification |
|---|---|---|
| G6.1 | Dijkstra overlay equals an independent reference (plain per-source Dijkstra / brute force) on random graphs, including unreachable nodes, tied sources and co-located sources | property test |
| G6.2 | Incremental update (charger removed / added) yields exactly the same overlay as a full rebuild, for random sequences of status changes | property test |
| G6.3 | A* returns a route whose length equals the Dijkstra distance and never expands more nodes than Dijkstra | property test |
| G6.4 | Per-event lookup is O(1): microbenchmark recorded (ns/op, allocs) | benchmark |
| G6.5 | Tenant visibility: a tenant never routes to another tenant's depot charger; public chargers visible to all | unit test |
| G6.6 | Decision rule: critical when the safety-discounted range cannot reach the nearest available charger, warning below the reserve margin, silent while charging/plugged, hysteresis against flapping; alert windows are deterministic so replays collapse | unit tests |
| G6.7 | Charger outage changes the decision within seconds in the live pipeline (status topic -> overlay -> alert) | integration test |
| G6.8 | Alert idempotency: the same alert delivered repeatedly yields exactly one PostgreSQL row; tenant isolation (RLS) holds for the alert service | integration test |
| G6.9 | Detection quality against simulator ground truth strandings: precision, recall and lead time of CRITICAL alerts, baseline rule vs per-vehicle EWMA estimator (MEASURED; declared limitation: ground truth comes from our own simulator) | evaluation run |
| G6.10 | Live latency: telemetry receive -> alert persisted/published, p50/p95/p99 at the real-time rate (target p99 < 5 s) | live run |
