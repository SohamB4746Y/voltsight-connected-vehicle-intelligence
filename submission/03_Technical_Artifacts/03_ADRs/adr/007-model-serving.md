# ADR-007 Range model and ML serving
**Decision:** the live range estimate is the per-vehicle **EWMA of %SoC per km** (learns each battery's real consumption, ageing and driver style without knowing them; falls back to catalogue capacity until 6 km are observed). The GBM consumption model (Python, scikit-learn) is trained and evaluated offline against baselines; its artefact is hashed and registered. **What was not built:** an in-process Go evaluator for the GBM with a parity test — so the GBM does not currently drive live alerts (its measured gain is reported separately; decision-level use of a model-driven prior is future work).
